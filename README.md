### 🔨 What I'm building

**In the open**
- 💬 **[Mnema Talk](https://github.com/msch128/mnema-talk)**: a self-hosted chat for one community. Text, voice, video and 4K60 screen sharing, with media end-to-end encrypted (MLS). One Go binary, PostgreSQL and S3, nothing else.
  - 🖥️ **[Mnema Talk Desktop](https://github.com/msch128/mnema-talk-desktop)**: its desktop client (Beta) for Windows, macOS and Linux, in Rust/Tauri and Electron. It verifies the signed web app it runs instead of trusting the server's JavaScript.
- 🚀 **[eaw-remake](https://github.com/msch128/eaw-remake)**: an unofficial Rust/Bevy engine for *Empire at War: Forces of Corruption*, Galactic Conquest and space battles. Bring your own game.

**Behind closed doors**
- 🔒 Laravel, Go and Rust applications that are closed source. You'll only ever see them in production.
